可重复分析项目模板

可重复分析要求另一名研究者拿到项目文件后，能够从只读原始数据生成同样的分析数据、图形和统计结果。口头补充的步骤、桌面上手改的表格和没有保存的 AI 对话，都不属于可重复流程。

推荐目录

project/
  README.md
  data/
    raw/          # 原始数据，只读
    clean/        # 由脚本生成
    dictionary/   # 数据字典与编码规则
  R/
    01_validate.R
    02_clean.R
    03_describe.R
    04_model.R
    05_report.R
  output/
    figures/
    tables/
  records/
    decisions.md
    changes.md
    ai-audit.md
  report.qmd

文件名前的数字说明运行顺序。脚本只读取 data/raw/，不覆盖原始文件。清洗数据、图形和表格都由脚本重新生成。

README 最少要写什么

项目名称：
研究问题：
数据来源与使用限制：
独立单位和样本量：
主要响应与主要比较：
软件环境：
运行顺序：
预计生成的文件：
联系人：

“先运行清洗脚本”还不够。要写出脚本名称、输入文件和输出文件。若运行需要手工选择文件、改工作目录或点击界面，也要改成明确指令。

数据处理记录

清洗脚本负责执行规则，records/changes.md 负责解释规则为什么存在。每条重要修改记录日期、字段、原值、修改后值、依据和复核人。

日期：2026-07-22
记录键：station_id = S018, year = 2, occasion = 4
问题：effort_nights = -6
处理：改为缺失，不直接改成 0
依据：现场日志记录相机未部署，0 会被解释为完成了零夜调查
复核：姓名或角色

不要把缺失值统一替换为 0，也不要删除离群点而不留痕。数据修正必须能回到原记录。

固定分析环境

报告中记录 R 版本、包版本、操作系统和随机种子。R 项目可以在报告末尾运行：

sessionInfo()

涉及随机化、bootstrap、交叉验证或模拟时，在代码附近设置并说明随机种子：

set.seed(20260722)

随机种子保证同一算法得到相同抽样结果，但不能修复不稳定的依赖版本。重要项目还应锁定包版本或保存可恢复的环境说明。

记录分析判断

模型选择不能只留最终公式。records/decisions.md 至少记录候选模型、排除理由、诊断结果和改变结论的条件。

问题：虫口密度使用 Poisson 还是负二项模型？
候选：Poisson、quasi-Poisson、负二项
检查：Poisson 离散统计量为 3.5
决定：使用负二项，另报 quasi-Poisson 敏感性分析
仍有风险：树木嵌套于小区，需要处理小区层级

保存 AI 使用记录

AI 生成的代码进入项目时，保存工具和版本、完整提示、原始输出、实际运行结果、人工修改及理由。只保存最终代码会丢失错误是怎样被发现的。记录格式见AI 提问模板与核查清单。

交付检查

交付前从一个新的工作目录重新运行。确认原始数据没有被改写，脚本没有依赖个人电脑的绝对路径，输出文件能重新生成，报告中的数字与当前输出一致，受限数据没有进入公开目录。

如果接收者必须先询问“这个文件从哪里来”或“这一步当时怎么做”，项目还没有完成可重复交付。

# 可重复分析项目模板

可重复分析要求另一名研究者拿到项目文件后，能够从只读原始数据生成同样的分析数据、图形和统计结果。口头补充的步骤、桌面上手改的表格和没有保存的 AI 对话，都不属于可重复流程。

## 推荐目录

```text
project/
  README.md
  data/
    raw/          # 原始数据，只读
    clean/        # 由脚本生成
    dictionary/   # 数据字典与编码规则
  R/
    01_validate.R
    02_clean.R
    03_describe.R
    04_model.R
    05_report.R
  output/
    figures/
    tables/
  records/
    decisions.md
    changes.md
    ai-audit.md
  report.qmd
```

文件名前的数字说明运行顺序。脚本只读取 `data/raw/`，不覆盖原始文件。清洗数据、图形和表格都由脚本重新生成。
